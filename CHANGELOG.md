# Changelog

No Dissidia files are included. Sora's model and sounds are fan-ported from Kingdom Hearts II.
Fan-made, not affiliated with Square Enix or Disney.

Built by Mat with help from AI tools (Claude, Codex).

## 1.1.0 (2026-10-25)
- The app has a "Fighters to add" list. Today it has one fighter, Sora, ticked from the start.
- Sora runs on a new fighter engine underneath, made so more fighters can be added later.
- The Opponent Info screen shows Sora's name correctly.
- Your 1.0 save keeps working. Build 1.1 from your original game file, not from the 1.0 file (the app tells you
  if you pick the old one).
- Before the new file gets its name, the app checks its SHA-256 and the list of fighters inside it.
- Tested in PPSSPP and on PS Vita with Adrenaline (start, battles, EX Mode, Reflect, EX Burst, saving and loading).
- Release format 3: the release data is one patch per fighter pack plus a small patch per mix of fighters.

## 1.0.0 (2026-10-20)
- Sora as a new fighter for Dissidia 012 (US, PSP): his own Keyblade combos, EX Mode, Reflect barrier and Trinity
  Limit EX Burst, built from his Kingdom Hearts II moves.
- Desktop app for Windows, macOS and Linux that patches your own copy; your original file is only read.
